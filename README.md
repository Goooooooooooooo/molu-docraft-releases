# Molu Docraft / 墨炉

**设计一次，反复填写，稳定输出。**

Molu Docraft 是一款面向业务文档的本地优先可视化模板设计与 PDF 生成工具。

它将**模板设计、结构化数据填写、实时预览和 PDF 导出**整合在一条工作流中，可用于制作报价单、发票、收据、采购单、交货单、工程单据、对账单，以及其他版式固定、需要重复填写的文档。

## What is Molu Docraft?

Molu Docraft is an independently developed document drafting and productivity application focused on reusable document templates and structured PDF generation.

Typical workflow:

```text
选择起点 → 设计模板 → 填写记录 → 实时预览 → 导出 PDF
```

主要能力包括：

- 可视化文档模板设计
- 结构化数据填写
- 实时文档预览
- PDF 导出
- 多记录批量输出
- Excel 数据交换
- 中文、日文、英文支持
- 本地优先的数据存储
- Web 和桌面版本

模板和输入记录默认保存在本地。多条记录可以合并为一个多页 PDF，也可以分别生成 PDF 并打包输出。
